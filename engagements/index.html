Internet

The Internet is a huge network that connects computers, phones, and other devices around the world so they can share information.

Web

The Web is a part of the Internet that lets people visit websites and view pages using a web browser.

How are the Internet and Web different?

The Internet is the network that connects devices together, while the Web is a service that uses the Internet to let us access websites and web pages.

ASCII and Unicode

ASCII is a character system that uses numbers to represent basic letters, numbers, and symbols. Unicode is a larger system that can represent characters from many different languages.

What is UTF-8?

UTF-8 is a way for computers to store and send text. It can represent many different characters and languages and also works with ASCII.

URL

A URL is the address of a website or a specific page on the Web. You type it into a browser to find the page you want.

Domain Name

A domain name is the easy-to-remember name of a website, such as google.com, that people use instead of typing an IP address.

HTTP

HTTP is a set of rules that allows a web browser and a web server to communicate and exchange information.

HTTPS

HTTPS is the secure version of HTTP. It helps protect information by encrypting the data sent between your browser and a website.

IP Address

An IP address is a number that identifies a device or server on a network. It helps information get sent to the right place.

DNS

DNS changes website names into IP addresses so computers can find the correct server for a website.

W3C Recommendations

W3C Recommendations are guidelines made by the World Wide Web Consortium to help make websites work properly and consistently.

XML

XML is a language used to organize and store information using tags. It allows people to create their own tags for different types of data.

XHTML

XHTML is a version of HTML that follows stricter rules for how web pages should be written.

HTML

HTML is the main language used to create the structure of web pages. It uses tags to organize things like headings, paragraphs, images, and links.

HTML5

HTML5 is a newer version of HTML that added features for things like videos, audio, graphics, and modern websites.
