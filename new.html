Questions and Answers

What kind of photos are good to encode using JPEG?

Photos with lots of colors and details, such as photographs.

What kind of photos are good to encode using GIF?

Simple images with few colors, such as logos, icons, and animations.

What is unique about the PNG format?

PNG supports transparent backgrounds and can preserve high image quality.

How do you resize your photo to the size it should be displayed?

Resize it using photo-editing software before adding it to the website.

Why should you resize photos using photo editing software instead of resizing it using CSS?

CSS only changes the displayed size; the original large file still takes longer to load.
